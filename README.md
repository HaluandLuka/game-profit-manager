# Game Profit Manager

ゲーム機の修理・販売を想定した、Python製のCLI利益管理アプリです。

仕入れ価格、部品代、送料、販売手数料、販売価格を登録し、
商品ごとの利益を自動計算・保存できます。

## 主な機能

- 商品の登録
- 商品一覧の表示
- 商品情報の編集
- 商品の削除
- 商品IDによる管理
- 利益の自動計算
- 利益額に応じた判定
- JSON形式でのデータ保存
- 入力値のバリデーション
- JSON破損時の自動バックアップ
- unittestによる自動テスト

## 利益計算

利益は以下の計算式で算出します。

販売価格 - 仕入れ価格 - 部品代 - 送料 - 販売手数料

利益額に応じて以下のように判定します。

- 3000円以上：利益十分
- 1円～2999円：利益あり
- 0円：収支ゼロ
- 0円未満：赤字

商品データとして生成される`items.json`およびバックアップファイルは、
`.gitignore`によりGitの管理対象外としています。

## 実行方法
```bash
python game_manager.py
```

初回起動時に商品データが存在しない場合は、空の状態で起動します。

商品を登録すると、同じフォルダに`items.json`が生成されます。

## テスト

以下のコマンドで自動テストを実行できます。
```bash
python -m unittest -v
```

現在、利益計算と利益判定について以下の境界値をテストしています。

- 3000円：利益十分
- 2999円：利益あり
- 1円：利益あり
- 0円：収支ゼロ
- -1円：赤字

## 工夫した点

### 入力値のチェック

商品名の空欄や、金額への文字列・負の値の入力を防止しています。

金額入力を共通関数にまとめることで、登録・編集処理の重複コードも削減しました。

### データの永続化

商品データをJSON形式で保存し、
アプリを終了しても次回起動時にデータを読み込めるようにしています。

保存ファイルは`pathlib`を使用して、
実行場所にかかわらずPythonファイルと同じフォルダを参照するようにしています。

### 破損データの保護

JSONファイルが破損していた場合は、
元ファイルを日時付きのバックアップファイルへ退避してから空の状態で起動します。

これにより、破損した元データを新しいデータで上書きしないようにしています。

### 自動テスト

利益判定が切り替わる境界値を中心に`unittest`でテストしています。

機能追加やコード修正後にもテストを実行することで、
既存機能が壊れていないことを確認できます。
